# Deck Blueprints by Goal & Audience Context

Use these proven slide-by-slide structures instead of letting an AI invent a generic topic list.

---

## 1. Audience Context Calibration

| Audience | Emphasis | Cut / Avoid |
|---|---|---|
| **Executive / Board** | Strategic thesis upfront, decision slide (recommendation, options, trade-off, ask), giant key numbers, 40–50% whitespace | Deep operational steps, raw logs, >12 slides |
| **Investor (Seed / Series)** | Market size (TAM/SAM/SOM), traction curve, unit economics, team credibility, clear ask | Feature-by-feature product tour, internal jargon |
| **Client / Sales Proposal** | Client's quantified pain, before/after peer proof, clear ROI, 2 concrete next-step options | Company history monologue, internal acronyms |
| **Engineering / Tech Share** | Specific pain point, architecture diagram, ~15-line crisp code block, benchmarks, when NOT to use it | Marketing fluff, blurry screenshots |
| **Teaching / Onboarding** | Curiosity hook, 3 core questions, visual analogies, common mistakes & fixes, 5-min exercise, quick quiz | Dense paragraphs, >6 lines per slide |

---

## 2. Six Ready-to-Use Slide Blueprints

### A. Client Sales Proposal (10 Slides)
1. **Cover + 1-Sentence Client Scenario**
2. **3 Quantified Pain Points** (Editorial Split or Consulting Columns — no 3 icon boxes)
3. **Solution Architecture Flow** (Vector Gate/Flow Diagram)
4. **3 Key Advantages** (1 crisp sentence each, zero adjectives)
5. **Peer Case Study** (Before/After data or Hero KPI breather)
6. **3-Phase Implementation Timeline** (Horizontal Node Timeline)
7. **Budget & Expected ROI** (Waterfall Bridge or Clean Comparison Table)
8. **Risks & Mitigations** (2-column matrix)
9. **3 Key Team Members** (Background-removed portraits + 1-line credential)
10. **Next Steps** (Give **2 concrete options** to move forward)

### B. Executive Board / Weekly Manager Review (7–10 Slides)
1. **Cover + Period Tag**
2. **SCQA Executive Summary** (Situation -> Complication -> Question -> Answer)
3. **Hero KPI Breather** (1 giant landmark figure)
4. **Completed Milestones** (Progress nodes / checkmarks)
5. **Key Metrics Table** (Last period vs This period vs `% Delta`, right-aligned `tabular-nums`)
6. **Trend or Variance Chart** (Axis-free Milestone Curve or Waterfall Bridge)
7. **Blockers** (Issue -> Root Cause -> Active Mitigation)
8. **Next-Period Plan**
9. **Single Decision / Help Needed** (Large centered statement)

### C. Seed Investor Pitch (10 Slides)
1. **Cover** (Bold promise + visual anchor)
2. **Problem** (Real cost/shift)
3. **Solution** (Large product visual + 3-word positioning)
4. **Market Size** (TAM / SAM / SOM direct-labeled bars)
5. **Traction** (Axis-free growth curve)
6. **Business Model** (Simple unit economics)
7. **Go-to-Market**
8. **Competitive Landscape** (Clean matrix, highlighted column)
9. **Team**
10. **The Ask & Use of Funds**

### D. Engineering Tech Share (15 Slides)
1. Title + Speaker -> 2. Specific Pain Point -> 3. Architecture Diagram -> 4. Comparison Table vs Alternatives -> 5–6. Core Concepts -> 7. ~15-Line Commented Code (Carbon/VS Code crisp) -> 8. Live Output -> 9. 3 Production Pitfalls -> 10. Before/After Benchmark Chart -> 11. When NOT to Use It -> 12. Migration Cost -> 13. 2 Recommended Reads -> 14. Blank Q&A -> 15. Contact.

### E. Teaching / Onboarding Deck (12 Slides)
1. Curiosity Hook -> 2. 3 Questions to Answer Today -> 3–7. Core Concepts (analogy diagram + everyday example + common misconception) -> 8. Concept Relationship Map -> 9. Common Mistakes & Fixes -> 10. 5-Minute Exercise -> 11. 3-Question Self-Quiz -> 12. Further Reading.

### F. Consumer Product Launch (8 Slides)
1. Name + Emotional Slogan (no specs) -> 2. Relatable Pain Scenario -> 3. Solution (large hero image + 3 keywords) -> 4. Top 3 Features (1 real product photo each) -> 5. 3 Real User Quotes -> 6. Clean Spec Table -> 7. Price & Buying Channels -> 8. Top 3 FAQs.
